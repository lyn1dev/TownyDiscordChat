[CENTER][SIZE=6][B]TownyDiscordChat 3.2.4[/B][/SIZE]
[SIZE=4]Towny Advanced [COLOR=#5865F2]↔[/COLOR] DiscordSRV bridge for Paper and Purpur[/SIZE]

[URL='https://github.com/smokytek/TownyDiscordChat']GitHub source[/URL] · [URL='https://www.spigotmc.org/resources/townydiscordchat.91026/']Original inspiration[/URL][/CENTER]

[B]TownyDiscordChat[/B] connects Towny Advanced towns and nations to DiscordSRV. It creates private Discord resources, provides secure town and nation chat bridges, synchronizes linked accounts and publishes useful Towny activity in rich embeds.

[SIZE=5][B]Highlights[/B][/SIZE]
[LIST]
[*][B]Town and nation resources:[/B] roles, private text channels and voice channels created and synchronized automatically.
[*][B]Town-only bridge:[/B] Minecraft town chat goes to the matching Discord channel and Discord messages go only to online residents of that town.
[*][B]Nation bridge:[/B] Minecraft nation chat goes to the matching nation channel and Discord messages are delivered only to online members of that nation.
[*][B]Global chat compatibility:[/B] DiscordSRV continues to handle global chat normally; TownyDiscordChat intercepts only messages detected as `town` or `nation` chat.
[*][B]Security:[/B] linked-account validation, wrong-town protection and Discord administrator overrides.
[*][B]No staff channel:[/B] town notifications are delivered in the normal town channel.
[*][B]Bank embeds:[/B] deposits, withdrawals, taxes, balances, actors and reasons with configurable fields.
[*][B]Town events:[/B] resident join/leave, mayor changes, rank changes, jail, outlaw and tax notifications.
[*][B]Daily NewDay summary:[/B] town status, economy, taxes, residents and spawn information.
[*][B]Interactive buttons:[/B] private Taxes, Residents and Outposts views from the daily summary.
[*][B]Residents and outposts:[/B] ranks, last access, PlotGroup names, worlds and coordinates with pagination.
[*][B]Town fall reports:[/B] global embeds for bankruptcy, ruin or fall with configurable story variants; NPC residents are excluded.
[*][B]Dynmap:[/B] `/town map` generates an overhead image of a town.
[*][B]InteractiveChat:[/B] item previews through InteractiveChat DiscordSRV Addon, plus a fallback embed for supported components.
[*][B]PlaceholderAPI:[/B] external placeholders work in bridge formats, titles, descriptions, footers and fields.
[*][B]Five locales:[/B] English, Italian, French, Spanish and Polish with English fallback.
[/LIST]

[SIZE=5][B]Installation[/B][/SIZE]
[LIST=1]
[*]Install Towny Advanced and DiscordSRV and configure DiscordSRV's Main Guild.
[*]Give the bot Manage Roles, Manage Channels, Manage Channel Permissions, View Channels, Send Messages, Embed Links and Read Message History.
[*]Place the bot role above TownyDiscordChat roles and enable Message Content Intent.
[*]Put the jar in `/plugins`, start once, edit `config.yml` and run `/tdc sync`.
[/LIST]

[SIZE=5][B]Language configuration[/B][/SIZE]
[CODE]
language: en
# Available: en, it, fr, es, pl
[/CODE]
The selected file is loaded from `plugins/TownyDiscordChat/locales/<language>.yml`. The five files are created automatically on first start, and missing keys fall back to English.

[SIZE=5][B]Example configuration[/B][/SIZE]
[CODE]
bridge:
  Enabled: true
  TownChatOnly: true
  RequireLinkedAccount: true
  RequireCurrentTown: true
  MinecraftFormat: "**[MC] %player%:** %message%"
  DiscordFormat: "&8[&2TDC&8] &c%titolo% &8» &7%usernameds% &8» &f%message%"
  NationMinecraftFormat: "**[MC] %player%:** %message%"
  NationDiscordFormat: "&8[&2NATION&8] &b%nazione% &8» &7%usernameds% &8» &f%message%"

townychat:
  TownChannelNames: ["town"]
  NationChannelNames: ["nation", "nc"]
  CommandListener:
    TownCommands: ["tc", "townchat", "town"]
    NationCommands: ["nc", "nationchat", "nation"]
    OtherCommands: ["g", "global", "globalchat", "a", "admin", "m", "mod"]

messages:
  DailySummaryButtons:
    Enabled: true
    TaxesLabel: "Taxes"
    ResidentsLabel: "Residents"
    OutpostsLabel: "Outposts"
  TownEvents:
    rank-add:
      Enabled: true
      Format: "🏅 **Rank:** %resident% received **%rank%** (by %actor%)."
    rank-remove:
      Enabled: true
      Format: "🏅 **Rank:** **%rank%** was removed from %resident% (by %actor%)."
    taxes:
      Enabled: true
      Format: "💰 **Taxes:** town tax set to **%tax%** (by %actor%)."
[/CODE]

[SIZE=5][B]Commands[/B][/SIZE]
[LIST]
[*]`/tdc sync`, `/tdc check role`, `/tdc channels delete <town|all>`, `/tdc channels restore <town|all>`.
[*]`/t discord <newday|chat|jail> <enable|disable>` for town feature toggles.
[*]`/town info`, `/town sync`, `/town map [town]`, `/town notice message:<text>`, `/town resync`.
[/LIST]

[SIZE=5][B]Compatibility and support[/B][/SIZE]
The plugin uses public Bukkit/Paper APIs only and no NMS. Towny, DiscordSRV and optional integrations must support your server version. Report issues through the [URL='https://github.com/smokytek/TownyDiscordChat/issues']GitHub issue tracker[/URL].
